机器人接入指南

〇、先说清楚：不需要口令，用你自己的 AppID + AppSecret

这套东西没有「共用口令」这一说。在网页「设置 → 我的机器人」里贴上 AppID + AppSecret，点一下「接入」就通了。

每个班用自己申请的机器人，填自己的 AppID 和 AppSecret， 数据走自己的通道 —— 天然隔离，谁也看不到谁。

你的 QQ 机器人 ──(你的 AppID/AppSecret 自动核验)──▶ 云函数 ──▶ 你自己班的群消息

云函数会拿你填的两样东西去 QQ 官方接口现场验一次： 能换到 access_token，说明凭据是真的，立刻给你发一枚接入令牌； 之后你打开班群摘要，看到的就是你这个机器人收到的消息，别人的机器人一条也进不来。

要填的从哪来
AppIDQQ 开放平台 → 你的机器人 → 开发设置
AppSecret同上（也叫 BotSecret / 密钥）
为什么不加口令？因为能拿到 AppSecret 的本来就是机器人主人 —— 凭据本身就是身份，再叠一层口令只是给自己添麻烦（旧版就是这么干的，现在已拆掉）。

一、你要准备什么

要什么干什么用去哪弄
QQ 开放平台账号申请机器人q.qq.com
腾讯云账号跑云函数（接收 QQ 推送）console.cloud.tencent.com，免费额度足够
GitHub 账号存代码（可选）github.com

都不花钱。腾讯云云函数每月有免费调用额度，一个班用不到千分之一。

二、第一步：申请 QQ 机器人（约 15 分钟）

  1. 打开 q.qq.com，用 QQ 登录，进「开发者中心」
  2. 创建一个机器人（个人主体就能申请，选「群聊机器人」方向）
  3. 进机器人详情页 → 开发设置，记下两样东西： 
    AppID      = 例如 1905465027      ← 一串数字
AppSecret  = 例如 JTdo0D...Ae9f   ← 一串字母数字
  4. 在功能配置里开启「群聊消息」相关权限（不同版本菜单名略有差别，找「事件订阅 / 消息推送」这一类）
⚠️ AppSecret 只在创建时显示一次，当场复制存好。丢了要重置。

三、第二步：部署接收端（约 20 分钟）

QQ 的服务器需要往一个公网 HTTPS 地址推送消息，所以得有个接收端。 本方案用腾讯云云函数（免备案、大陆可连通、有免费额度）。

3.1 建函数

  1. 打开 console.cloud.tencent.com/scf
  2. 左侧「函数」→「新建」
  3. 配置（这几项必须对）：
    • 函数类型：Web 函数（不是事件函数！Web 函数才收 HTTP）
    • 运行环境：Nodejs16.13
    • 启动命令：./scf_bootstrap
  4. 上传代码 ZIP（根目录直接放 scf_bootstrap / server.js / handler.js）
  5. 提交

3.2 配环境变量（这里填你自己的）

函数详情页 →「函数配置」→「环境变量」：

变量名填什么说明
GH_TOKEN你的 GitHub 令牌存数据用（代码里读，不放前端）
GH_REPO_QQ你/私有库必须私有库：群消息只落这里
PUBLIC_BASE你的函数地址用来算回调地址给用户复制
ADMIN_TOKEN自己编一串随机字符站长后台用（可选）
WATCH_GROUPS你的群号，留空=不限只想收某个群的消息就填
注意 BOT_SECRET 不是必填的 —— 这让「接入」完全搬到网页上完成： 每个班在「设置 → 我的机器人」里自己填 AppID / AppSecret， 云函数记在私密库里；不用去腾讯云控制台改环境变量，也不用站长插手。

3.3 拿到回调地址

函数创建好后，在触发器里能看到一个网址，形如：

https://1499683192-953ux74r8x.ap-guangzhou.tencentscf.com

这串地址每个函数都不一样，复制你自己的那串，填到环境变量 PUBLIC_BASE 里。

之后网页上接入时，会自动给你算出该填进 QQ 的回调地址，形如 你的函数地址/qq?bot=你的AppID —— 路径末尾带 AppID， 所以一个云函数可以同时接好几个班的机器人，各收各的，互不串号。

四、第三步：把地址告诉 QQ（约 5 分钟）

回到 q.qq.com 的机器人后台 → 开发设置 → 消息推送 / Webhook 配置：

  1. 回调地址填网页上接入成功后给你的那段（形如 …/qq?bot=你的AppID）
  2. 保存

QQ 会立刻发一条验证请求过来，云函数会用你这个机器人的密钥自动签名回它。配置保存成功 = 通了。

验证失败通常是三种原因：
① 地址填错（少了 https://）　② 网页上 AppSecret 填错　③ 函数还在 Updating 状态，等 30 秒再试

五、验证一下

在网页「设置 → 我的机器人」里点「接入」，成功后会显示 ✓ 已接入，凭据已核验（云函数拿你的凭据去 QQ 官方换到了 access_token）。 之后在群里发一条消息，打开「待办 → 班群摘要」就能看到 —— 不用输任何口令。

也可以直接看函数自检：你的函数地址/health，里面 bots 字段是已经接入的机器人数。

六、几个必须知道的坑

坑说明
intents 别乱加实测 33554433（= GUILDS + GROUP_AND_C2C_EVENT）是能通过鉴权的值。再加 AT_MESSAGES 会被腾讯拒绝（op=9）
函数类型必须是 Web 函数选成「事件函数」收不到 HTTP 回调
改完代码要重新打包上传否则传的还是旧 zip
环境变量在 process.env腾讯云 Node 运行时是 Node.js 原生环境，不是 Web 标准环境
函数刚建好是 Updating等 20–30 秒再测，否则测的是旧版本
AppSecret 只显示一次丢了只能重置；网页上填过就存进私密库了，不会丢
私有库别选错GH_REPO_QQ 必须是 Private 仓库 —— 群消息只落本机/私密库，这是硬红线

七、不想自己部署怎么办

如果你只是想看公告和教材，不想折腾机器人 —— 完全不用接机器人。

文库站（网页版那套）是独立的，不需要机器人也能跑：

  • 教材浏览 ✓
  • AI 问答 ✓（每人自己填 API Key）
  • 官网公告待办 ✓（定时抓取，不需要机器人）

只有「把班群消息自动收进来」这一件事需要机器人。

八、验收清单

  • ☐ q.qq.com 上机器人已创建，拿到 AppID + AppSecret
  • ☐ 腾讯云函数已建，类型是 Web 函数、运行时 Nodejs16.13
  • ☐ 环境变量 GH_TOKEN / GH_REPO_QQ（私有库）/ PUBLIC_BASE 已填
  • ☐ 网页「设置 → 我的机器人」贴 AppID + AppSecret → 点接入 → 显示「✓ 已接入，凭据已核验」
  • ☐ QQ 后台的回调地址填的是接入成功后显示的那段（带 ?bot=你的AppID），保存成功
  • ☐ 群里发测试消息，「待办 → 班群摘要」里能看到，全程没输过任何口令
