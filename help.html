〇、先说清楚：这是一个 Agent（智能体）

蛇杖二号不是一个"搜索框"，也不是普通的问答机器人 —— 它是一个 Agent。

什么叫 Agent？它会自己决定"去查什么、查几轮"，然后带着出处回答你。 你不用告诉它去哪本书找，它自己翻。

普通问答机器人蛇杖二号（Agent）
怎么找资料你问一句，它翻一次自己决定查哪本书、要不要再查一轮
过程看得见吗看不到看得见：它会先列出「调了哪些工具」，再给答案
出处常常没有每个结论都带角标，答案下方有「引用对照」卡
查不到会怎样可能会编直接说「没找到」，不许编造出处
能自己动手吗只会说会调工具：查文库、读章节、联网、读公告、读你的附件
所以第一次用会觉得「它怎么先动了几下才回答」—— 那正是它在查书，不是卡住了。

一、这是个什么东西

一座临床医学教材库，加一个会查书的 AI Agent。

  • 底子是 50 册教材（人卫版为主）的原文
  • 你提问 → 它自己去库里翻原文 → 带着出处回答
  • 回答里每个关键结论都带角标，最下方那张「引用对照」卡就是它的字典

它能干：概念讲解、复习备考、病例分析思路、实验报告、资料整理、出题练习、列背书大纲。
它不能干：代替医生诊断，代替现行指南，代替你自己读书。

〇之二、要用 AI，得先自己填接口和 Key ⚠️

这一站本身不含任何 API Key，每位使用者要填自己的。 不填的话，文库能看、公告能查，但问 AI 不会回答。

填法（一次性，存在你自己浏览器里，不会上传）：

  1. 点右上角 设置
  2. 三个格子：
    • 接口地址：填 https://api.deepseek.com/v1（DeepSeek 官方） 或 https://api.siliconflow.cn/v1（硅基流动，有免费模型）
    • API Key：去上面那家平台注册，在「API Keys」里新建一个，复制进来（形如 sk-…）
    • 模型名：DeepSeek 填 deepseek-chat；硅基流动可填 Qwen/Qwen2.5-7B-Instruct
  3. 点 保存，回对话页直接提问即可

费用说明：按各家平台自己的价格扣你自己的账户余额。DeepSeek 新号通常有赠送额度； 硅基流动有若干免费模型。本工具不代收、不抽成，也不碰你的 Key。

二、怎么开始用

  1. 打开网址，输入访问密码（班长发的那个）
  2. 在下方输入框打字，按 Enter 发送（Shift+Enter 换行）
  3. 等它回答。你会先看到它「查了什么」，再看到答案——这是故意的，方便判断它有没有认真查
第一次打开要等十几秒载入文库索引（1.6 MB 密文要在浏览器里解密），属正常，之后就快了。

七、回答里的角标怎么读

AI 会标三种角标，答案最下方那张「📎 引用对照」卡就是它们的字典：

角标意思卡片里给什么
〔1〕〔2〕…教材原文书名 · 章节
〔网1〕〔网2〕…联网查到的来源 · 标题
〔待办1〕〔待办2〕…学校 / 图书馆公告标题 · 截止日期 · 「原文 ↗」可点

十一、常见问题

为什么第一次打开很慢？

文库索引是加密的（1.6 MB），要在浏览器里解密，十几秒正常。

它会不会瞎编？

设计上要求「工具没返回的内容不许编」，查不到会直接说查不到。 但你仍应核对——尤其剂量、诊断、数值这类，一律以现行指南和医嘱为准。

回答很慢 / 报错？

可能接口在抽风。点答案下方的「🔁 换端点」，或到设置里换模型。

手机上怎么装成 App？

安卓 Chrome 打开网页 → 菜单 → 「添加到主屏幕」；桌面 Chrome 地址栏右侧也有安装图标。

我能看到别的同学问过什么吗？

不能。会话记录只存在你自己浏览器里。

班群摘要是空的？

先确认口令对不对。还是空，说明群里最近没有值得收录的通知（闲聊不收）。
